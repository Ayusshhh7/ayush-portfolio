# Ayush Chaudhary — Personal Portfolio

A sleek, responsive personal portfolio website built with pure HTML, CSS, and vanilla JavaScript.

## Features
- **Modern Responsive Design**: Clean hero layout with custom typography (`Space Grotesk` & `Inter`).
- **Interactive Navigation**: Sticky backdrop-filtered navigation bar with smooth scrolling, active section scrollspy, and mobile hamburger drawer.
- **Projects Showcase**: Featured project showcase for **Market Desk**, with cards for **Smart Resume Parsing System** and **PG Life**.
- **Skills & Toolkit**: Categorized skill tags (C++, DSA, Web Dev, Node.js, Express.js, MongoDB, MySQL).
- **Interactive Journey Timeline**: Milestones highlighting ongoing learning and building.
- **Direct Connect**: Mailto link and profile links to GitHub, LinkedIn, and LeetCode.

## Running Locally
1. Open `index.html` directly in any modern web browser.
2. No build tools, external CLI dependencies, or packages required.
